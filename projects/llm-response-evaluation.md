# LLM Response Evaluation — Sample Work

**Focus:** Response quality, instruction-following, factuality, relevance, and clarity.

## Objective
Demonstrate a consistent framework for reviewing AI-generated answers and explaining quality judgments.

## Evaluation dimensions
- **Instruction-following:** Did the answer satisfy the user's request and constraints?
- **Factuality:** Are claims supported and free from obvious contradictions?
- **Relevance:** Does the answer directly address the question?
- **Clarity:** Is the response organized and understandable?
- **Safety and tone:** Is the response appropriate and respectful?

## Example review template

| Dimension | Review question | Rating |
|---|---|---|
| Instruction-following | Were all requested parts completed? | 1–5 |
| Factuality | Are important claims accurate and appropriately qualified? | 1–5 |
| Relevance | Is unnecessary material minimized? | 1–5 |
| Clarity | Is the answer easy to follow? | 1–5 |

## Deliverable
A structured score and concise evidence-based rationale identifying the strongest answer and the main improvement needed.
