# Search Quality Review — Sample Work

**Focus:** Relevance, usefulness, freshness, and trustworthiness.

## Objective
Provide a repeatable checklist for assessing whether a search result meets the user's likely intent.

## Review checklist
1. **Intent match:** Does the result answer the actual query?
2. **Relevance:** Is the main content closely related to the request?
3. **Trustworthiness:** Is the source appropriate for the claim being made?
4. **Freshness:** Does the query require current information, and is the result current enough?
5. **Usefulness:** Can the user act on the information provided?
6. **Coverage:** Does the result omit a critical part of the request?

## Example scoring rubric

| Score | Meaning |
|---|---|
| 3 | Strong match; directly useful |
| 2 | Partial match; useful with limitations |
| 1 | Weak match; largely misses intent |

The rating should be supported by a short rationale, not just a score.
