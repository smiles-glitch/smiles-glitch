# Prompt Engineering — Sample Work

**Focus:** Clear instructions, constraints, output format, and evaluation criteria.

## Objective
Show how a broad request can be rewritten as a precise prompt that produces more consistent outputs.

## Example

**Before:** “Summarize this feedback.”

**Improved prompt:** “Summarize the feedback in 3–5 bullets. Group recurring themes, distinguish praise from concerns, do not invent details, and include one short representative paraphrase for each theme. If the feedback does not support a conclusion, say so.”

## Why the revision helps
- Defines the output length and format.
- Specifies how to organize information.
- Adds a grounding requirement.
- Makes uncertainty handling explicit.

## Quality checklist
- Is the task unambiguous?
- Are constraints and output format stated?
- Does the prompt discourage unsupported claims?
- Can the result be evaluated against clear criteria?
